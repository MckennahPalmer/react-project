# React Web Page Project

Quick start:

```
$ yarn # npm install
$ yarn build # npm run build
```

## Development

Run Webpack in watch-mode to continually compile the JavaScript as you work:

````
$ yarn watch # npm run watch
# react-project

Author: McKennah Palmer

This is a small React webpage I built while taking a course to prepare for interviews. It demonstrates a simple component structure and a Webpack-based build pipeline.

What you'll find here

- A minimal React app (Header, Main, Footer).
- A Webpack config that builds a bundle to `dist/index.pack.js`.

Run locally

```bash
# from the project root
npm install        # install dependencies
npm run build      # build the production bundle into dist/

# optional: watch mode during development
npm run watch

# serve the folder (simple):
# python3 -m http.server 8000
# then open http://localhost:8000
````
